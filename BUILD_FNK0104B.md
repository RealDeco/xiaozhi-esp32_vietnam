# Сборка прошивки FNK0104B с радио и русскими станциями

## Что было сделано

### 1. Добавлены русские радиостанции

В файле `main/features/music/esp32_radio.cc` добавлены станции:

- **Маруся FM** (`MARUSYAFM`) - `http://radio.marusya.fm:8000/stream.mp3`
- **Русское Радио** (`RUSSKOE_RADIO`) - `https://rusradio.hostingradio.ru/rusradio96.aacp`
- **Европа Плюс** (`EUROPA_PLUS`) - `https://ep256.hostingradio.ru:8052/ep256`

### 2. Добавлена поддержка AAC декодера

В `main/features/music/esp32_radio.cc` обновлена функция `InitializeDecoder()`:
- Сначала пробуется MP3 декодер
- Если MP3 не подходит, автоматически используется AAC декодер
- Это необходимо для Русского Радио (AAC поток)

### 3. Создана конфигурация платы FNK0104B

Созданы файлы:
- `main/boards/fnk0104b/config.h` - конфигурация пинов
- `main/boards/fnk0104b/fnk0104b.h` - заголовочный файл
- `main/boards/fnk0104b/fnk0104b.cc` - реализация платы

### 4. Реализовано сенсорное управление громкостью

В файле `fnk0104b.cc` добавлена обработка жестов:

- **Свайп вверх** - увеличить громкость (+10)
- **Свайп вниз** - уменьшить громкость (-10)
- **Свайп вправо** - следующая станция
- **Свайп влево** - предыдущая станция
- **Двойной тап** - переключить состояние чата
- **Долгое нажатие** - выключить звук

### 5. Плата добавлена в систему сборки

- `main/CMakeLists.txt` - добавлена опция `CONFIG_BOARD_TYPE_FNK0104B`
- `main/Kconfig.projbuild` - добавлен выбор платы FNK0104B

## Сборка прошивки

### Требования

1. **ESP-IDF v6.0.1 или выше** (рекомендуется v6.1)
2. Python 3.8+
3. Git

### Установка ESP-IDF

```bash
# Клонируйте репозиторий ESP-IDF
git clone --recursive https://github.com/espressif/esp-idf.git
cd esp-idf
git checkout v6.1
git submodule update --init --recursive

# Установите инструменты
install.bat
export.bat
```

### Настройка и сборка

```bash
# Перейдите в директорию проекта
cd C:\Users\А\Documents\Проект по умолчанию\xiaozhi-esp32

# Настройте проект для FNK0104B
idf.py set-target esp32s3
idf.py menuconfig

# В menuconfig выберите:
# -> Board type
#    -> FNK0104B

# Соберите прошивку
idf.py build

# Прошейте устройство
idf.py flash
```

## Использование радио

### Голосовые команды

После запуска устройства вы можете использовать голосовые команды:

- "Включи радио" - включит радио
- "Включи Маруся ФМ" - включит Маруся FM
- "Включи Русское Радио" - включит Русское Радио
- "Включи Европа Плюс" - включит Европа Плюс

### Сенсорное управление

- **Свайп вверх** - громкость +
- **Свайп вниз** - громкость -
- **Свайп вправо** - следующая станция
- **Свайп влево** - предыдущая станция
- **Долгое нажатие** - выключить звук

## Настройка радиостанций

Чтобы изменить или добавить станции, отредактируйте файл:
`main/features/music/esp32_radio.cc`

Функция `InitializeRadioStations()` содержит список всех станций.

## Примечания

1. **FNK0104B** - это плата на базе ESP32-S3 с сенсорным LCD дисплеем
2. Конфигурация пинов в `config.h` может потребовать корректировки в зависимости от конкретной ревизии платы
3. Для работы радио требуется подключение к Wi-Fi
4. Убедитесь, что у вас есть аккаунт на [xiaozhi.me](https://xiaozhi.me) для работы голосового ассистента

## Устранение проблем

### Проблема: Не собирается проект
- Убедитесь, что ESP-IDF установлен и настроен
- Проверьте версию ESP-IDF (требуется v6.0.1+)

### Проблема: Не работает радио
- Проверьте подключение к Wi-Fi
- Убедитесь, что радиостанции доступны из вашей сети
- Проверьте настройки громкости

### Проблема: Не работает сенсорное управление
- Проверьте подключение сенсора к I2C
- Убедитесь, что правильно указаны пины в `config.h`
- Проверьте адрес сенсора (по умолчанию 0x15)
