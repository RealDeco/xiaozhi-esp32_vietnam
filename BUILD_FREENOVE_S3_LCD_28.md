# Сборка прошивки Freenove ESP32-S3 Display 2.8" (XiaoZhi + радио)

Полная прошивка голосового ассистента XiaoZhi (RealDeco/xiaozhi-esp32_vietnam)
для платы **Freenove ESP32-S3 Display 2.8-inch LCD** с интернет-радио
(русские станции), сенсорным управлением громкостью и функцией смены Wi-Fi.

## Что было сделано

### 1. Русские радиостанции
Файл `main/features/music/esp32_radio.cc`, функция `InitializeRadioStations()`:

- **Маруся FM** (`MARUSYAFM`) — `https://msk3.radio-holding.ru/marusya_default` (MP3; сайт marus.fm отдаёт HLS, но у холдинга есть прямой MP3-стрим)
- **Русское Радио** (`RUSSKOE_RADIO`) — `https://rusradio.hostingradio.ru/rusradio96.aacp` (**AAC**)
- **Европа Плюс** (`EUROPA_PLUS`) — `https://ep256.hostingradio.ru:8052/europaplus256.mp3` (MP3; старый адрес `.../8052/ep256` уже не отдаёт поток, 404)

### 2. Декодер MP3 + AAC (с выбором по станции)
- В `esp32_radio.h` добавлено поле `codec` у станции (`STATION_CODEC_MP3` / `STATION_CODEC_AAC`).
- `InitializeDecoder()` выбирает декодер по типу станции (с автоматическим fallback).
- Это обязательно для **Русского Радио** — поток в формате AAC+ (`.aacp`).

### 3. Конфигурация платы
- `main/boards/freenove-esp32-s3-lcd-2.8/config.h` — пины и параметры
- `main/boards/freenove-esp32-s3-lcd-2.8/freenove-esp32-s3-lcd-2.8.cc` — реализация платы

Железо (проверено на реальной плате FNK0104B):
- Дисплей **ILI9341 240×320**, SPI3, 20 МГц, BGR, инверсия вкл., `MIRROR_X = true`
- Тач **FT6336U** (совместим с драйвером FT5x06), I2C, адрес **0x38**
- Звук: **ES8311** (кодек, I2S + I2C), усилитель на PA-пине GPIO1

Пины (подтверждены рабочей прошивкой):

| Функция | GPIO |
|---|---|
| LCD SCLK | 12 |
| LCD MOSI | 11 |
| LCD MISO | 13 |
| LCD CS | 10 |
| LCD DC | 46 |
| LCD RST | — (NC, сброс по RST платы) |
| LCD BL | 45 |
| Touch SDA / SCL | 16 / 15 |
| Touch INT / RST | 17 / 18 |
| ES8311 MCLK | 4 |
| ES8311 BCLK | 5 |
| ES8311 DIN (микрофон) | 6 |
| ES8311 WS/LRCK | 7 |
| ES8311 DOUT (динамик) | 8 |
| ES8311 PA | 1 |
| ES8311 I2C адрес | `ES8311_CODEC_DEFAULT_ADDR` |

### 4. Сенсорное управление (жесты)
- **Свайп вверх** — громкость +10
- **Свайп вниз** — громкость −10
- **Свайп вправо** — **следующая радиостанция** (если радио не включено — запускает первое)
- **Долгое нажатие** — выключить звук (мьют)
- **Двойной тап** — вкл/выкл чат (при первом запуске без Wi-Fi — настройка Wi-Fi)

### 5. Смена подключения к Wi-Fi (несколько способов)
1. **Иконка Wi-Fi в статус-баре** (правый верхний угол) — тап по иконке подсвечивает её,
   повторный тап в течение 5 секунд подтверждает и перезагружает устройство в режим настройки
2. **5 нажатий кнопки BOOT** подряд
3. **Голосом/через LLM** — инструмент MCP `self.system.reconfigure_wifi`
4. Двойной тап / одиночное нажатие BOOT при старте, если Wi-Fi ещё не настроен

Во всех случаях устройство перезагружается в **режим точки доступа (AP)** —
подключитесь к сети устройства и укажите новую Wi-Fi сеть.

### 6. Веб-интерфейс управления станциями (на русском)

После подключения к Wi-Fi запускается веб-сервер на порту **8080**.
Откройте в браузере: `http://<IP-устройства>:8080/radio`

На странице можно:
- Посмотреть список всех станций (встроенные + свои)
- Добавить станцию: название, URL потока, жанр, громкость, кодек (MP3/AAC)
- Редактировать свои станции
- Удалять свои станции (встроенные нельзя удалить)
- Переключать воспроизведение на любую станцию кнопкой «Играть»

Свои станции сохраняются в NVS и остаются после перезагрузки.

### 7. Плата добавлена в сборку
- `main/CMakeLists.txt` — `CONFIG_BOARD_TYPE_FREENOVE_ESP32_S3_LCD_2_8`
- `main/Kconfig.projbuild` — пункт выбора платы «Freenove ESP32-S3 Display 2.8 inch LCD»

## ВАЖНО: выбор платы в sdkconfig

Самая частая причина «прошил, а экран мёртвый» — **в `sdkconfig` выбрана не та плата**.
Проверьте, что там стоит именно:

```
CONFIG_BOARD_TYPE_FREENOVE_ESP32_S3_LCD_2_8=y
```

Если в `sdkconfig` остался старый символ (например `CONFIG_BOARD_TYPE_FNK0104B=y`
от ранних экспериментов), CMake соберёт каталог `boards/fnk0104b` и **все правки в
`boards/freenove-esp32-s3-lcd-2.8/` просто не попадут в прошивку**.

Быстрая проверка, что в сборку попал нужный код:

```powershell
Select-String -Path build\build.ninja -Pattern "boards/freenove"
```

В `build.ninja` должен быть объект
`.../boards/freenove-esp32-s3-lcd-2.8/freenove-esp32-s3-lcd-2.8.cc.obj`.

А в загрузочном логе — строка `Board: ... SKU=freenove-esp32-s3-lcd-2.8`.

Тип дисплея: если ваша панель **ST7789**, а не ILI9341, замените в
`.cc` строку `esp_lcd_new_panel_ili9341(...)` на `esp_lcd_new_panel_st7789(...)`
(и добавьте `#include <esp_lcd_panel_st7789.h>`).

## Сборка

### Требования
1. **ESP-IDF v5.5.6** (проверено; подойдёт любая 5.5.x)
2. Python 3.8+
3. Git

### Команды (Windows)

```bat
:: Активируйте окружение ESP-IDF (путь к вашей установке)
call C:\Espressif\frameworks\esp-idf-v5.5.6\export.bat

:: Перейдите в проект
cd /d C:\Projects\xiaozhi-esp32

:: Цель — ESP32-S3 (один раз)
idf.py set-target esp32s3

:: Выбор платы (один раз)
idf.py menuconfig
::  -> Board type
::      -> Freenove ESP32-S3 Display 2.8 inch LCD

:: Сборка
idf.py build

:: Прошивка (плата подключена по USB)
idf.py -p COM5 flash
idf.py -p COM5 monitor
```

Если `idf.py flash` падает с `Could not open COM5, the port is busy` — закройте
монитор/программы, держащие порт. Если в середине прошивки появилось
`Lost connection, retrying...` и процесс упал — просто повторите `idf.py -p COM5 flash`.

> Из PowerShell вывод `idf.py` может валиться на `UnicodeEncodeError: 'charmap'`
> (кодировка cp1251). Помогает запуск через `cmd /c "..."` или перенаправление вывода в файл.

После прошивки: при первом запуске устройство поднимет Wi-Fi точку доступа —
подключитесь к ней с телефона/ПК и выберите свою сеть.

## Использование

### Радио
- Голосом: «Включи радио», «Включи Маруся FM», «Включи Русское Радио», «Включи Европа Плюс»
- Свайп **вправо** по экрану — следующая станция
- В веб-интерфейсе — кнопка «Играть» у станции

### Сенсорные жесты

| Жест | Действие |
|---|---|
| Свайп вверх | Громкость +10 |
| Свайп вниз | Громкость −10 |
| Долгое нажатие | Mute (громкость 0) |
| Свайп вправо | Следующая радиостанция |
| Двойной тап | Начать / остановить чат |

### Смена Wi-Fi
- Иконка **Wi-Fi в верхней панели**: два тапа подряд (в течение 5 с) — сброс Wi-Fi и режим точки доступа
- **5 нажатий BOOT** подряд
- Голосом (LLM вызывает `self.system.reconfigure_wifi`)
- Одиночное нажатие BOOT, если плата не подключена к Wi-Fi

После сброса подключитесь к точке доступа платы с телефона и выберите сеть.

## Веб-интерфейс станций

Адрес: `http://<IP платы>:8080/radio` — IP печатается в логе строкой
`WifiStation: Got IP: ...`, например `http://192.168.3.108:8080/radio`.

Возможности: список станций, добавление, редактирование, удаление, кнопка «Играть».
Свои станции сохраняются в NVS (в логе — `Loaded N custom stations from NVS`).

API:

| Метод | URI | Назначение |
|---|---|---|
| GET | `/radio` | HTML-страница (русская) |
| GET | `/radio/api/stations` | JSON со списком станций |
| POST | `/radio/api/stations` | добавить/изменить (`key`, `name`, `url`, `genre`, `volume`, `codec`) |
| POST | `/radio/api/stations/<key>/play` | включить станцию |
| DELETE | `/radio/api/stations/<key>` | удалить станцию |
| GET | `/radio/api/ota` | текущий адрес OTA-сервера (`{"url": "..."}`) |
| POST | `/radio/api/ota` | задать адрес OTA-сервера (`{"url": "http://..."}`, пустая строка — сбросить) |
| GET | `/radio/api/rotation` | текущий поворот экрана (`{"rotation": 0}`) |
| POST | `/radio/api/rotation` | повернуть экран (`{"rotation": 90}`, допустимо 0/90/180/270) |

> ⚠️ **Если страница не открывается и `ping` до платы не идёт** — почти всегда виноват
> **VPN на компьютере** (WireGuard / AmneziaWG / Cloudflare WARP): туннель забирает весь
> трафик, включая локальную сеть. Отключите туннель на время или откройте страницу
> с телефона в той же Wi-Fi-сети. Проверьте также, что ПК и плата в одной подсети.
>
> Признак именно этой проблемы: не пингуется даже роутер (`General failure`),
> а в `arp -a` устройство видно с правильным MAC.

## Поворот экрана

Экран 240×320 по умолчанию вертикальный. Повернуть интерфейс можно тремя способами:

1. **Веб-интерфейс**: `http://<IP платы>:8080/radio` → блок «🖥️ Поворот экрана» →
   выбрать 0°, 90°, 180° или 270°. После сохранения плата автоматически
   перезагружается (~2 с), чтобы перестроить раскладку под новый размер.
2. **Голосом / MCP**: `self.screen.set_rotation` с `rotation_degree = 90`.
3. **HTTP API**: `POST /radio/api/rotation` с телом `{"rotation": 90}`.

Выбранный угол сохраняется в NVS (namespace `display`, ключ `rotation_degree`)
и применяется при каждой загрузке **до** построения интерфейса. 90° и 270° дают
горизонтальную ориентацию 320×240, 180° — перевёрнутый вертикальный экран.

Жесты тачскрина (свайпы громкости/станций, тап, двойной тап, долгое нажатие)
тоже пересчитываются под текущий угол: направления свайпов соответствуют
тому, что видно на экране.

## Обновление прошивки по Wi-Fi

USB нужен только для первой прошивки. Дальше обновляться можно по сети.

### Вариант 1. Вручную через встроенную страницу

1. Соберите прошивку: `idf.py build` → `build/xiaozhi_vn.bin`
2. Откройте `http://<IP платы>/ota` (порт 80)
3. Перетащите `.bin` на страницу и нажмите «Загрузить»

Устройство запишет образ во второй OTA-раздел и перезагрузится.

### Вариант 2. Автоматически через локальный сервер

В проекте есть `tools/ota_server/ota_server.py` — простой HTTP-сервер на Python
(только стандартная библиотека), который отдаёт JSON проверки версии и сам `.bin`.

Запуск (двойной клик по `tools/ota_server/start_ota_server.bat` или):

```bat
cd /d C:\Projects\xiaozhi-esp32
python tools\ota_server\ota_server.py
```

Сервер напечатает адреса, например:

```
Адрес    : http://192.168.3.2:8090/ota/
Файл     : http://192.168.3.2:8090/firmware/xiaozhi_vn.bin
```

Порт по умолчанию **8090** (8080 занят веб-интерфейсом радио), меняется `--port`.

Один раз укажите адрес на устройстве — он сохранится в NVS:

- в веб-интерфейсе `http://<IP платы>:8080/radio`, блок «🔄 Обновление прошивки»;
- или инструментом `self.system.set_ota_url` (`url=http://192.168.3.2:8090/ota/`);
- проверить: `self.system.get_ota_url`;
- вернуть по умолчанию: `url=default` (или пустое поле в веб-интерфейсе).

Дальше цикл обновления такой:

1. Поднимите версию в `CMakeLists.txt`: `set(PROJECT_VER "2.0.6.00")`
2. `idf.py build` — сервер читает версию прямо из `.bin`, перезапускать его не нужно
3. Перезагрузите устройство (кнопкой, `self.reboot` или по питанию)
4. В логе будет `Check version URL: http://...`, затем `New version available: ...`,
   `Progress: ...` и перезагрузка уже в новую версию

Особенности:

- сервер может работать на любом ПК в той же сети (Python 3.8+);
- при первом запуске Windows спросит про доступ в сеть — разрешите для частных сетей;
- если сервер выключен, устройство просто не найдёт обновлений (загрузка не блокируется);
- версию в JSON нельзя завышать: если она больше реальной версии в файле,
  устройство будет обновляться на каждом старте. Сервер специально берёт её из `.bin`;
- `--force` заставляет обновиться даже на ту же версию (для тестов).

## Устранение проблем

### Не собирается
- Нужен ESP-IDF **v5.5.x** (проверено на v5.5.6), окружение активировано.
- Убедитесь, что цель — `esp32s3` и выбрана плата `FREENOVE_ESP32_S3_LCD_2_8`.

### Нет изображения (подсветка есть / экран тёмный)
1. Проверьте `CONFIG_BOARD_TYPE_FREENOVE_ESP32_S3_LCD_2_8=y` в `sdkconfig` (см. раздел выше) —
   это самая частая причина.
2. В логе должно быть `ili9341: LCD panel create success` и `Backlight: Set brightness to 75`.
3. Пин подсветки — GPIO45, панель ILI9341 240×320, режим SPI3, 20 МГц, BGR, инверсия вкл.
4. Если панель ST7789 — замените `esp_lcd_new_panel_ili9341(...)` на `esp_lcd_new_panel_st7789(...)`.

### Устройство перезагружается / assert в `Es8311AudioCodec`
- ES8311 требует **одинаковых** частот входа и выхода: `AUDIO_INPUT_SAMPLE_RATE == AUDIO_OUTPUT_SAMPLE_RATE` (сейчас 24000/24000).
- Адрес кодека должен быть `ES8311_CODEC_DEFAULT_ADDR`, не произвольное число.

### Не работает тач
- Контроллер **FT6336U**, драйвер `esp_lcd_touch_new_i2c_ft5x06`, адрес **0x38**.
- Пины: SDA 16, SCL 15, INT 17, RST 18. **Эти пины не должны пересекаться с I2S-пинами** —
  ранее аудио было настроено на те же GPIO, из-за чего тач не работал.
- Если лог забит `No touch detected`, это уровень `ESP_LOGV` — включён только при verbose-логе.

### Нет звука
- Пины: MCLK 4, BCLK 5, DIN 6, WS 7, DOUT 8, PA 1; `use_mclk = true`, `pa_inverted = true`.
- Усилитель включается пином PA (GPIO1) — при неверной полярности будет тишина.

### Русское Радио не играет
- Поток AAC+ (`https://rusradio.hostingradio.ru/rusradio96.aacp`), для него нужен
  `STATION_CODEC_AAC` в описании станции (декодер выбирается автоматически с fallback на MP3).
- Поток должен быть доступен из вашей сети (нужен HTTPS и открытый исходящий трафик).

### Экран показывает пустые квадраты вместо русских букв
- Стандартные шрифты LVGL (`font_puhui_basic_16_4`) не содержат кириллицу — при
  отображении русских названий станций применяется транслитерация
  (`Esp32Radio::ToDisplayAscii`, «Маруся FM» → «Marusia FM»). Если нужно — добавьте
  в `managed_components/78__xiaozhi-fonts/src` шрифт с кириллицей и используйте его.

### Экран не реагирует на жесты / тихой звук при старте
- Громкость по умолчанию теперь **70** (если пользователь её не сохранил ранее) —
  раньше дефолт был `0` и плата начинала с тихим/отсечённым звуком.
- Жесты: свайп вверх/вниз ±10, долгое нажатие — mute, свиайп вправо — следующая станция, двойной тап — чат.
