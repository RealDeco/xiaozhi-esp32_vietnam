# Локальный OTA-сервер XiaoZhi

Простой HTTP-сервер (Python 3.8+, только стандартная библиотека), который
позволяет обновлять прошивку по Wi-Fi, без USB и без облака.

## Запуск

```bat
cd /d C:\Projects\xiaozhi-esp32
python tools\ota_server\ota_server.py
```

или двойным кликом по `start_ota_server.bat`.

Сервер напечатает примерно такое:

```
  Прошивка : C:\Projects\xiaozhi-esp32\build\xiaozhi_vn.bin
  Версия   : 2.0.5.06  (xiaozhi_vn, 3.3 МБ)
  Адрес    : http://192.168.3.2:8090/ota/
  Файл     : http://192.168.3.2:8090/firmware/xiaozhi_vn.bin
```

## Что отдаёт

| URI | Назначение |
|---|---|
| `GET/POST /ota/` | JSON `{"firmware": {"version", "url", "size", "force"}}` — проверка версии |
| `GET /firmware/xiaozhi_vn.bin` | файл прошивки |
| `GET /` | страница со статусом и журналом проверок |
| `GET /health` | `{"status":"ok"}` |

Версия и размер читаются из `esp_app_desc_t` внутри `.bin` на каждый запрос,
поэтому после `idf.py build` сервер сразу отдаёт новую версию — перезапускать
его не нужно.

## Настройка устройства (один раз)

Самый простой способ — веб-интерфейс радио на плате:
`http://<IP платы>:8080/radio` → блок «🔄 Обновление прошивки» → вставить
`http://192.168.3.2:8090/ota/` → «Сохранить». Адрес применяется после
перезагрузки устройства.

То же самое инструментом MCP `self.system.set_ota_url`:

```
self.system.set_ota_url  url=http://192.168.3.2:8090/ota/
```

Адрес сохраняется в NVS (namespace `wifi`, ключ `ota_url`) и применяется при
следующей загрузке. Проверить: `self.system.get_ota_url`, сбросить: `url=default`
(или пустое поле в веб-интерфейсе).

### HTTP API на устройстве

| Метод | URI | Назначение |
|---|---|---|
| GET | `/radio/api/ota` | `{"url": "...", "enabled": true}` |
| POST | `/radio/api/ota` | `{"url": "http://..."}` (пусто — сбросить) |

## Как выпустить обновление

1. Поднять версию в `CMakeLists.txt`: `set(PROJECT_VER "2.0.6.00")`
2. `idf.py build`
3. Перезагрузить устройство — оно проверит версию, скачает прошивку и
   перезагрузится уже с новой версией.

В логе устройства: `Check version URL: http://...` → `New version available: ...`
→ `Progress: ...` → перезагрузка.

## Параметры

```
--bin PATH      путь к .bin (по умолчанию build/xiaozhi_vn.bin)
--port PORT     порт (по умолчанию 8090)
--bind ADDR     адрес прослушивания (по умолчанию 0.0.0.0)
--force         force=1 в JSON: обновиться даже на ту же версию
--version VER   подменить версию (только для тестов)
```

> Важно: не завышайте версию вручную. Если сервер предложит версию больше той,
> что реально прошита, устройство будет обновляться при каждом старте.
> Штатно версия берётся из самого файла прошивки.
